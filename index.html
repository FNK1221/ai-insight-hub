入门
什么是人工智能？
人工智能（AI）是让计算机模拟人类智能行为的技术。核心：不是魔法，是"用数据+算法让机器自动完成任务"。

一句话定义：AI = 给机器大量数据 + 算法，让它自动完成过去只有人类才能做的事。

关键区分——弱AI vs 强AI：

  • 弱AI（专用AI）：只在一个领域厉害，比如下棋的AlphaGo不会写文章。目前所有AI产品都属于弱AI。
  • 强AI（AGI，通用人工智能）：像人一样什么都能学、能推理、有意识。还没实现，是终极目标。

普通人怎么理解：把AI想象成"超级实习生"——它读了整个互联网的书，能快速帮你查资料、写初稿、做总结，但它不知道自己说的是不是真的，需要你来把关。

💡 普通人怎么用
1. 打开 chatgpt.com 或 kimi.moonshot.cn（国内免费）
2. 输入："帮我用通俗语言解释XX"——它就是你的私人老师
3. 重要：AI会"编"——任何事实性信息必须自己核实

入门
机器学习 vs 深度学习
机器学习是AI的子集，深度学习是机器学习的子集——层层递进，越来越"聪明"，但也越来越"黑箱"。

三者的关系（俄罗斯套娃）：

  • AI（最外层）：让机器表现出智能 → 包含机器学习
  • 机器学习ML（中间层）：给数据，让机器自己找规律 → 不需要手写规则
  • 深度学习DL（最内层）：用多层神经网络自动提取特征 → 不需要人工设计特征

举个例子：

  • 传统编程：你写规则"如果邮件含'中奖'→垃圾邮件"
  • 机器学习：你给它10万封邮件+标签，它自己找到区分垃圾邮件的规律
  • 深度学习：连"找规律"这步都不用你管，神经网络自动学会

2026年最新数据：NVIDIA 报告显示，MoE架构使模型智能实现了近70倍增长。排名前10的开源模型全部使用MoE架构。

入门
ChatGPT 为什么这么"聪明"？
核心原理就一句话：读了几乎整个互联网的文字，然后学会了"预测下一个词"。规模大到产生质变。

训练过程（4步走）：

  1. 收集数据：读了互联网上几乎所有的公开文字（网页、书籍、代码、论文...）
  2. 做填空题：把一些词遮住，让模型猜——猜错就调整参数，猜对了就加强
  3. 人类反馈（RLHF）：让人类标注员评分"哪个回答更好"，教模型更"有用+安全"
  4. 持续迭代：GPT→GPT-3.5→GPT-4→GPT-5.4，每代模型更大、训练数据更多

2026年GPT-5.4数据：上下文窗口105万tokens，在GDPval基准上达83.0%（人类专家72.4%）。据Ethan Mollick分析，每7小时任务可节省约4小时38分钟。

局限（很重要）：

  • 幻觉：会编造不存在的事实——这是它最大的问题
  • 知识有截止日期，不知道训练之后发生的事
  • 没有真正的"理解"和"世界观"——它是统计机器，不是人
💡 怎么用好ChatGPT
✓ 好用法："帮我对比A和B的优缺点" / "用小白能懂的话解释XX"
✓ 好用法："帮我修改这段文字让它更简洁"
✗ 坏用法：直接问"XX是不是真的"然后不核实就信了
✗ 坏用法：让它做需要精确数学计算的事（它容易算错）
🌎 来源：OpenAI / Ethan Mollick 分析

进阶
Transformer：改变一切的架构
2017年Google提出的"注意力机制"，是GPT、BERT、Claude等所有大模型的地基。

核心创新——自注意力（Self-Attention）：

传统模型逐词阅读（像人读书），Transformer是"一眼看全文"——每个词同时和所有其他词建立关联。

为什么这很重要：

  • "苹果"在"吃了一个苹果"和"买了苹果手机"里意思不同——自注意力能根据上下文自动区分
  • 可以并行处理（不用一个词一个词来），训练速度提升数百倍
  • 这就是为什么2017年后AI突然爆发——Transformer让"大力出奇迹"成为可能
💡 你需要知道什么
当有人说"这个模型基于Transformer"——意思就是它用了自注意力机制，这是当前所有主流AI模型的基础架构
知道这个就够了——不需要理解数学细节，除非你要做AI研发
🌎 来源：Google "Attention Is All You Need" (2017)
进阶
微调（Fine-tuning）：让通用模型变专家
预训练模型像"读过万卷书的通才"，微调是让它去"某个行业实习"变成专家。

两阶段过程：

  1. 预训练（Pre-training）：在大规模数据上学习通用知识——像上大学读通识课
  2. 微调（Fine-tuning）：在特定领域数据上继续训练——像去医院实习成为专科医生

举个例子：

  • 通用GPT-4：能聊任何话题，但不懂你公司的内部流程
  • 微调后的模型：用你公司的1000份文档微调后，它就像一个老员工了

LoRA（低秩适应）：2026年最流行的微调方法。不需要改全部参数，只改一小部分——成本降90%，效果几乎一样。普通人也可以用开源工具给自己的数据做微调。

💡 普通人怎么用
你不需要自己微调——用各家平台的"知识库"功能（如ChatGPT的GPTs、Kimi的知识库）就能达到类似效果
原理：你上传文档 → 平台在对话时自动检索相关内容 → 回答就带上了你的专业知识
🌎 来源：Microsoft LoRA Paper / Hugging Face
进阶
多模态AI：看图、听音、说话
以前AI只会"读文字"，现在能同时理解文字+图片+音频+视频——这就是多模态。

什么是"模态"：信息的不同形式——文字是一种模态，图片是另一种，音频又是另一种。

多模态能做什么：

  • 拍一张菜的照片问AI："这菜怎么做？"→ 它能看图回答
  • 发一段会议录音问AI："帮我总结重点"→ 它能听音回答
  • 给它一段文字描述，它生成图片（Midjourney/DALL-E）
  • 给它一段文字脚本，它生成视频（Sora/Runway）
💡 普通人怎么用
1. 用ChatGPT的图片功能：拍照→发给它→让它识别/分析/翻译
2. 用Gamma做PPT：输入文字大纲→自动生成带图的PPT
3. 用即梦AI/可灵AI（国内免费）：文字→生成视频
🌎 来源：OpenAI GPT-4V / Google Gemini
前沿
MoE（混合专家）：为什么模型变大了但速度没慢
2025-2026年最重要的AI架构突破。排名前10的开源模型全部使用MoE。

核心思想：不是所有参数都参与每次计算——有一个"路由器"决定每个输入由哪些"专家"处理。

类比：去医院看病，不是所有医生都看你——导诊台（路由器）把你分给对应科室（专家）。虽然医院有1000个医生，但每次看病只有2-3个参与。

为什么MoE是2026年的王者：

  • NVIDIA报告：MoE使模型智能实现了近70倍增长
  • 一个1万亿参数的MoE模型，每次推理只激活约100-200亿参数
  • 效果≈1万亿参数的全量模型，但计算成本只有1/5
  • 超过60%的2025年开源模型采用MoE架构
🌎 来源：NVIDIA Blog / Artificial Analysis Leaderboard
前沿
RLHF：怎么让AI"听话"
让AI既能干又不会乱来——这就是"对齐"问题，RLHF是目前最主流的解决方案。

问题：纯粹的"预测下一个词"会让AI学到互联网上的偏见、有害内容、错误信息。

RLHF三步法：

  1. 监督微调（SFT）：让人类标注员写高质量的问答示例，教模型"好回答长什么样"
  2. 训练奖励模型：人类对多个AI回答打分排序，训练一个"品味模型"
  3. 强化学习优化：让AI生成回答，用奖励模型打分，高分回答被强化

2026年新方法——Constitutional AI（Anthropic）：不靠人类逐条打分，而是让AI根据一组"宪法原则"自己评估自己的回答——成本更低、可扩展性更强。

🌎 来源：OpenAI / Anthropic / DeepMind

术语
LLM（大语言模型）
你天天听到的"大模型"就是这个。核心：读了海量文字，学会了预测下一个词。

是什么：Large Language Model，用海量文本数据训练的超大规模语言模型。代表：GPT-4、Claude、Gemini、Llama、Qwen、DeepSeek。

用在哪：聊天助手、代码编写、文档总结、翻译、问答、内容生成——几乎所有AI文字应用。

"大"是什么意思：参数量。GPT-3有1750亿参数，GPT-4据估计超1万亿。参数越多，模型越"聪明"——但也越贵。

💡 普通人怎么用
✓ 免费体验：Kimi（月之暗面）、通义千问、豆包——国内免费，无需翻墙
✓ 付费进阶：ChatGPT Plus（$20/月）或 Claude Pro（$20/月）——综合能力最强
✓ 最实用的场景：让它帮你写邮件、总结长文、翻译、写代码、头脑风暴

术语
Prompt / 提示词工程
Prompt就是你给AI的指令。Prompt Engineering是"怎么写指令让AI输出更好"的技术——这是普通人最该学的AI技能。

是什么：Prompt是你输入给AI的文字。同一个问题，不同的提问方式会得到截然不同的答案。学会写好Prompt，等于学会了"跟AI高效沟通"。

4个万能Prompt模板：

  1. 角色法："你是一个10年经验的XX专家，请..."
  2. 结构法："请按以下结构回答：1.背景 2.分析 3.建议 4.风险"
  3. 示例法："参考以下示例的格式和风格：[给一个例子]，请用同样的方式写..."
  4. 约束法："请用500字以内、小学生能懂的语言、不要用专业术语来说明..."
💡 马上能用的5个Prompt
1. "帮我把这段话改写成适合发朋友圈的语气：[原文]"
2. "你是一个资深HR，请帮我优化这段简历描述：[原文]"
3. "请用费曼学习法解释[概念]，要求用生活中的例子类比"
4. "帮我写一封委婉拒绝的邮件，对方是[关系]，原因是[原因]"
5. "请给我5个关于[主题]的创意方案，每个方案用3句话说清"
🌎 来源：OpenAI Prompt Engineering Guide / Anthropic
术语
RAG（检索增强生成）
让AI先"查资料"再回答，而不是靠记忆瞎编——这是解决AI幻觉的关键技术。

是什么：Retrieval Augmented Generation。AI回答问题前，先从外部知识库中检索相关文档，再基于这些文档生成答案。

类比：普通AI = 闭卷考试（靠记忆答，可能记错）；RAG = 开卷考试（先翻书再答，准确率大增）。

用在哪：企业知识库问答、法律文档查询、医疗辅助诊断、客服系统——任何需要"准确引用"的场景。

💡 普通人怎么用
1. 最简单：用ChatGPT的"GPTs"功能，上传你的文档，它自动做RAG
2. 用Kimi的"知识库"功能：上传PDF/文档 → 对话时自动检索 → 回答带引用
3. 进阶：用Dify/Coze搭建自己的RAG知识库（零代码，免费）
我上传了一份文档，请基于文档内容回答我的问题。
如果文档中没有相关信息，请明确说"文档中未提及"。
回答时请标注引用的原文段落。

我的问题：[你的问题]
🌎 来源：Meta RAG Paper / LangChain / Dify

AI Agent（AI代理/智能体）
2026年最火的AI概念。不再是"你问它答"，而是"你给它目标，它自己规划步骤并执行"。

是什么：能自主感知环境、做出决策、执行动作的AI系统。和普通聊天的区别：它有"行动力"。

Chatbot vs Agent：

  • Chatbot：你问"附近有什么好吃的" → 它回答文字建议 → 你自己去点
  • Agent：你说"帮我订一家附近评分4.5以上的日料" → 它自己搜索→比较→预订→给你确认

2026年数据：79%的企业已采纳AI代理，每个组织平均拥有31个代理式AI工作流。

💡 普通人怎么用
1. ChatGPT的Operator模式：让它帮你自动订餐、购物、填表
2. 用Coze/扣子搭建自己的AI Agent：设目标→给工具→自动执行
3. 用Cursor（编程Agent）：描述你要什么→它自动写代码→自动调试

要求：
1. 先告诉我你的执行计划（分几步，每步做什么）

4. 最终输出一份完整的成果总结

术语
Token / 上下文窗口
Token是AI理解文字的最小单位。上下文窗口是AI一次能"记住"多少内容——直接影响你能喂多少资料。

Token是什么：AI不按"字"或"词"理解，而是按Token。1个汉字≈1-2个Token，1个英文单词≈1个Token。

上下文窗口（Context Window）：AI一次能处理的最大Token数。超过就"忘了"前面的内容。

2026年主流模型的窗口：

  • GPT-5.4：105万tokens（约75万汉字——相当于一部长篇小说）
  • Claude 4：20万tokens
  • Gemini 2.5 Pro：100万tokens
💡 对你意味着什么
窗口大 = 你可以一次性扔给它一本200页的PDF，它能从头读到尾
窗口小 = 你需要分段喂给它，它可能"忘了"前面的内容
选工具时先看窗口大小——需要处理长文档的，选窗口大的
🌎 来源：OpenAI / Anthropic / Google
术语
Embedding / 向量数据库
让AI理解"意思"而非"字面"的技术。是搜索、推荐、RAG的底层基础。

Embedding是什么：把文字变成一组数字（向量），让意思相近的文字在"数字空间"里也相近。

类比：把"开心"和"高兴"变成坐标，它们在空间里靠得很近；而"开心"和"悲伤"离得远。这样AI就能理解语义相似度。

向量数据库：专门存储和检索这些"数字表示"的数据库。代表：Pinecone、Milvus、Chroma。

用在哪：语义搜索（搜意思不是搜关键词）、RAG（找到最相关的文档片段）、推荐系统。

💡 普通人怎么用
你不需要直接操作向量数据库——所有"知识库"功能（Kimi、ChatGPT GPTs）底层都在用
想深入了解：用Dify搭建一个RAG应用，它会自动处理Embedding和向量存储
🌎 来源：Pinecone / Milvus / LangChain
热词
AIGC（AI生成内容）
AI Generated Content——用AI自动生成文字、图片、视频、音乐、代码等内容。

是什么：用AI自动创作各种形式的内容。区别于"AI分析数据"，AIGC强调"创造新东西"。

普通人能用的AIGC工具：

  • 文字：ChatGPT/Claude/Kimi → 写文案、写邮件、写报告
  • 图片：Midjourney/即梦AI/Nano Banana 2 → 生成营销图、设计稿
  • 视频：Sora/可灵AI/Runway → 文字描述生成视频
  • PPT：Gamma → 输入大纲自动生成PPT
  • 音乐：Suno/Udio → 描述风格自动生成歌曲
💡 普通人怎么赚钱
1. 帮小店做产品图：用AI生成电商主图，一套收200-500元
2. 做自媒体：AI写脚本+生成图片/视频→小红书/抖音
3. 帮人写材料：AI起草+你润色→代写简历/方案/文案
注意：纯AI生成的内容越来越容易被检测——关键是加"人的判断和修改"
🌎 来源：McKinsey / WEF
热词
Copilot（AI副驾驶）
不是替代你开车，而是坐在副驾驶帮你导航。核心概念：人做决策，AI做执行。

是什么：微软提出的概念，AI作为你的"智能助手"嵌入到你日常工作流中，随时协助。

各种Copilot：

MCP（模型上下文协议）
2024年底Anthropic提出的开放协议——让AI能连接任何外部工具和数据源，像USB接口一样。

是什么：Model Context Protocol。一个开放标准，让AI模型可以安全地连接到外部数据源和工具。

类比：USB接口让任何设备都能连电脑；MCP让任何工具/数据源都能连AI。

为什么重要：以前每个AI工具都需要单独开发集成。有了MCP，开发者只需写一次接口，所有支持MCP的AI都能用。

2026年现状：OpenAI、Google、Microsoft都宣布支持MCP。它正在成为AI连接外部世界的"标准插座"。

💡 普通人怎么用
你不需要懂MCP的技术细节——当AI工具说"支持MCP"时，意味着它能连接更多外部工具
用Claude Desktop + MCP服务器 → 让AI直接读取你的本地文件、搜索网页、操作数据库

GPT/Claude是闭源（用不了底层），Llama/DeepSeek/Qwen是开源（能自己部署）。各有适用场景。

核心
介护保险：日本最核心的制度创新
不是"有保险就行"，而是"怎么运作的、花了多少钱、效果如何"——这是中国正在试点的制度。

运作方式：

  1. 参保：40岁以上国民强制参保（65岁以上为第一类，40-64岁为第二类）
  2. 缴费：保费从养老金/工资中自动扣除，约占收入的0.8-1.2%
  3. 评估：需要护理时，由护理经理上门评估，分为7个护理等级（要支援1→要护理5）
  4. 服务：根据等级提供居家护理、日间照料、短期入住、机构入住等服务
  5. 支付：个人承担10%（高收入者20-30%），保险支付剩余部分

效果数据：

  • 覆盖约600万护理认证者
  • 2023年护理费用约13万亿日元（约880亿美元）
  • 使家庭照护负担显著减轻，特别是减少了"照护离职"（因照顾家人而辞职）

对中国的参考：中国49个城市正在试点"长期护理保险"——参照的正是日本的介护保险制度。区别：中国目前的覆盖范围和保障水平远低于日本。
